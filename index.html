Why a proxy?

GitHub Pages is public, so a Gemini key placed in this page would be visible to everyone. Requests go to your Worker, which adds the secret key server-side and forwards them to Google.

  1. Create a Worker and paste worker.js.
  2. Add the secret GEMINI_API_KEY.
  3. Set ALLOWED_ORIGINS to your https://<user>.github.io.
  4. Paste the Worker URL above and press Test connection.
